# Grocery System

A browser-based grocery management application for organizing products, quantities, and shopping-related records through a simple user interface.

## Features

- Add and manage grocery items
- Track quantities and item details
- Interactive client-side experience
- Responsive layout for everyday use

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

```bash
git clone https://github.com/sameer-softengs/grocery-system.git
cd grocery-system
```

Open `index.html` in a modern browser, or run the project with any local static server.

## Project Structure

- `index.html` — application markup
- `script.js` — application logic
- `styles.css` — presentation and responsive styling
